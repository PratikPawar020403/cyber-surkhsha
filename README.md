# CyberSuraksha

CyberSuraksha is a responsive cybercrime-reporting experience concept created to improve the accessibility and usability of cybercrime.gov.in for Indian citizens.

## Features

- Clear 1930 emergency guidance
- Guided cybercrime reporting flow
- Scam checks, safety tips, suspect lookup, and complaint tracking demo
- Hindi support, high-contrast mode, font controls, and read-aloud support
- Responsive layout for mobile, tablet, and desktop

## Run locally

Open `index.html` in a browser, or serve the folder with:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

> This is a UI/UX competition prototype. Complaint submission and tracking are simulated.
